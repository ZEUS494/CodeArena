# Высота Кода — пошаговый запуск на GitHub Pages + Supabase (бесплатно)

Проект полностью готов к бесплатному размещению на **GitHub Pages** (сайт) + **Supabase** (база данных PostgreSQL, живая синхронизация Realtime, серверная проверка ответов и постоянный архив результатов с разбором ошибок).

---

## Шаг 1. Настройка базы данных в Supabase (5 минут)

1. Перейдите на [https://supabase.com](https://supabase.com) и войдите (удобнее через аккаунт GitHub).
2. Нажмите **New project**:
   - **Name**: `vysota-koda` (или любое удобное имя).
   - **Database Password**: придумайте и сохраните пароль.
   - **Region**: выберите ближайший (например, `Central EU (Frankfurt)`).
   - **Pricing Plan**: `Free`.
   - Нажмите **Create new project** и подождите ~1–2 минуты.
3. В левом меню Supabase откройте **SQL Editor** → нажмите **New query**.
4. Откройте файл `supabase/schema.sql` из этого проекта, скопируйте **весь его текст**, вставьте в SQL Editor и нажмите **Run**.
   - Вы должны увидеть сообщение `Success. No rows returned`.
   - Этот скрипт автоматически создаёт таблицы комнат, участников, живых подъёмов, постоянного архива результатов, включает **Realtime** и создаёт серверную функцию проверки всех 30 задач (чтобы ученики не могли подсмотреть ответы в браузере).
5. Получите 2 ключа подключения:
   - В левом меню перейдите в **Project Settings** (иконка шестерёнки) → **API** (или **Data API** / **API Keys**).
   - Скопируйте:
     - **Project URL** (вида `https://xxxxx.supabase.co`) — это будет `VITE_SUPABASE_URL`.
     - **anon / public key** (или **Publishable key**) — это будет `VITE_SUPABASE_ANON_KEY`.

---

## Шаг 2. Загрузка проекта на GitHub

1. Создайте новый **публичный** репозиторий на [https://github.com/new](https://github.com/new) (например, `vysota-koda`).
   - *Примечание: бесплатный GitHub Pages работает для публичных (Public) репозиториев.*
2. Скачайте файлы этого проекта, распакуйте архив и загрузите их в созданный репозиторий (через `git push` или через кнопку **Add file → Upload files** на GitHub).

   Если используете терминал (Git):
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Vysota Koda"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/vysota-koda.git
   git push -u origin main
   ```

---

## Шаг 3. Добавление ключей Supabase в GitHub Secrets

1. Откройте ваш репозиторий на GitHub → вкладка **Settings** → в левом меню **Secrets and variables** → **Actions**.
2. Нажмите **New repository secret** и добавьте по очереди:
   - Name: `VITE_SUPABASE_URL` → Value: ваш **Project URL** из Шага 1.
   - Name: `VITE_SUPABASE_ANON_KEY` → Value: ваш **anon public key** из Шага 1.
   - *(Опционально, но очень рекомендуется для урока)* Name: `VITE_TEACHER_PIN` → Value: например `2025` (PIN-код для входа на вкладки **Сцена ведущего**, **Результаты** и **Задания**, чтобы ученики не могли переключиться на экран учителя и подсмотреть ответы).

---

## Шаг 4. Включение GitHub Pages

1. В репозитории откройте **Settings** → **Pages** (в левом меню).
2. В разделе **Build and deployment** → **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** вверху репозитория → выберите workflow **Deploy to GitHub Pages** → нажмите **Run workflow** (или он запустится автоматически после следующего коммита).
4. Через ~1–2 минуты появится зелёная галочка и постоянная ссылка вида:
   `https://ВАШ_ЛОГИН.github.io/vysota-koda/`

---

## Шаг 5. Как проводить соревнование

1. Откройте сайт по вашей ссылке (введите `VITE_TEACHER_PIN`, если задавали его).
2. Нажмите кнопку **Копировать** в блоке «Ссылка для учеников» — ссылка автоматически ведёт сразу на экран входа ученика (`?role=student`).
3. Ребята (до **16 человек**) вводят имя, фамилию, выбирают язык (`C++`, `C#`, `Python`) и группу (`Группа 1`, `Группа 2`, `Группа 3`), кастомизируют своего персонажа в лобби.
4. Выберите время таймера (например, 40 или 45 минут) и нажмите **Старт соревнования**.
5. Переключайтесь между отдельными экранами **Группа 1**, **Группа 2**, **Группа 3**, чтобы показывать ход каждой группы на проекторе.
6. Когда все закончат, выйдет время или вы нажмёте **Стоп — пьедестал**, появится экран пьедестала (1, 2 и 3 места по каждой группе и в общем зачёте), а все результаты автоматически сохранятся в Supabase.
7. В любой день позже откройте вкладку **Результаты** на сайте — там хранятся все прошедшие этапы, баллы, точный список задач с ошибками (включая неправильные ответы, которые вводили ученики) и кнопка **Скачать CSV (Excel)**.

## Полезно знать про бесплатный тариф Supabase

- Если к проекту в Supabase **7 дней подряд** вообще никто не обращался, Supabase ставит базу на паузу. Перед занятием зайдите в [https://supabase.com/dashboard](https://supabase.com/dashboard) и нажмите **Restore project** (база включится за ~1–2 минуты, все прошлые результаты полностью сохранятся).
- Для локального тестирования на своём компьютере:
  ```bash
  npm install
  npm run dev
  ```
  Откройте `http://localhost:3000`.
